# Unity Crop

[English documentation](README.md)

Unity Crop — многопоточная CLI-утилита, которая экспортирует отдельные спрайты из PNG sprite sheet по данным его Unity-файла `.meta`.

## Возможности

- рекурсивный обход целого Unity-проекта;
- параллельная обработка независимых sprite sheets;
- один цикл декодирования PNG на весь sheet;
- glob-маски включения и исключения файлов;
- настраиваемые шаблоны папок и имён;
- безопасная обработка совпадающих имён;
- проверка координат и понятный итоговый отчёт;
- режим предварительного просмотра `--dry-run`;
- готовые бинарники для Windows, Linux и macOS.

## Быстрый старт

Для одного каталога:

```console
unity-crop --input ./in --output ./out
```

Для целого Unity-проекта:

```console
unity-crop \
  --input /path/to/MyGame \
  --output /path/to/ExportedSprites \
  --recursive
```

По умолчанию пропускаются служебные каталоги `.git`, `Library`, `Temp`, `Logs`, `obj`, `Build` и `Builds`. Выходной каталог также исключается из обхода, если он находится внутри входного.

Исходный PNG должен иметь соседний файл с полным именем `<image>.png.meta`. В Unity у текстуры должен быть включён Sprite Mode `Multiple`, а спрайты должны быть нарезаны в Sprite Editor.

## Аргументы

```text
-i, --input <PATH>            PNG или каталог; по умолчанию: in
-o, --output <PATH>           корень экспорта; по умолчанию: out
-r, --recursive               обходить вложенные каталоги
-j, --jobs <N>                число потоков; 0 = автоматически
    --include <GLOB>           включить пути по маске; можно повторять
    --exclude <GLOB>           исключить пути по маске; можно повторять
    --no-default-excludes      не использовать встроенные исключения Unity
    --follow-links             переходить по символьным ссылкам
    --path-template <TEMPLATE> шаблон каталога внутри output
    --name-template <TEMPLATE> шаблон имени PNG
    --collision <MODE>         error | skip | overwrite | rename
    --dry-run                  показать план без записи файлов
    --fail-fast                остановить запуск новой работы после ошибки
-v, --verbose                  вывести каждый обработанный путь
-h, --help                     полная встроенная справка
-V, --version                  версия программы
```

## Маски файлов

`--include` и `--exclude` принимают glob-маски путей относительно `--input`:

```console
unity-crop -i ./MyGame -o ./Export -r \
  --include 'Assets/UI/**/*.png' \
  --exclude '**/Drafts/**'
```

Аргумент можно повторить. Если `--include` не задан, используются `*.png` и `**/*.png`.

## Шаблоны имён и путей

Доступны подстановки:

| Подстановка | Значение |
|---|---|
| `{sprite}` | имя спрайта из `.meta` |
| `{sheet}` | имя исходного PNG без расширения |
| `{relative_dir}` | каталог PNG относительно `--input` |
| `{index}` | номер спрайта, начиная с 1 |
| `{x}`, `{y}` | координаты Unity |
| `{width}`, `{height}` | размер спрайта |

Пример, сохраняющий структуру проекта и добавляющий имя sheet:

```console
unity-crop -i ./MyGame -o ./Export -r \
  --path-template '{relative_dir}/{sheet}' \
  --name-template '{sheet}_{index}_{sprite}.png'
```

Недостающие каталоги создаются автоматически. Недопустимые для Windows символы в именах заменяются на `_`. Абсолютные пути и `..` в шаблоне запрещены, поэтому результат не может выйти за пределы `--output`.

## Совпадения имён

- `rename` — режим по умолчанию; добавляет `_2`, `_3` и далее;
- `skip` — оставляет существующий файл;
- `overwrite` — заменяет существовавший до запуска файл, но сообщает об ошибке, если два спрайта текущего запуска получили один путь;
- `error` — сообщает об ошибке при любом совпадении.

Перед большим экспортом удобно проверить результат:

```console
unity-crop -i ./MyGame -o ./Export -r --dry-run --verbose
```

## Многопоточность

Единицей параллельной работы является sprite sheet. Каждый PNG декодируется один раз, после чего из него последовательно экспортируются спрайты. Разные sheets выполняются одновременно. Такой подход ускоряет экспорт проекта и ограничивает пиковое потребление памяти.

`--jobs 0` использует автоматически выбранное количество потоков. Для очень больших текстур можно уменьшить параллелизм, например `--jobs 4`.

## Сборка из исходников

Требуется стабильный Rust:

```console
cargo build --release --locked
cargo test --locked
```

Бинарник появится в `target/release/unity-crop` (`unity-crop.exe` на Windows).
